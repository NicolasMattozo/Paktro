# Interface acessível

1. Verifique nomes acessíveis e a estrutura semântica.
2. Percorra o fluxo principal usando somente o teclado.
3. Confira foco, mensagens de erro e contraste.
4. Teste em telas estreitas e com zoom.
5. Documente problemas reproduzíveis e correções.
