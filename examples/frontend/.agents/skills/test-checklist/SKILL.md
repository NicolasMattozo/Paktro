# Checklist de testes

1. Identifique a linguagem, a ferramenta de testes, os comandos documentados e o comportamento esperado.
2. Defina casos de sucesso, erro e valores de fronteira.
3. Implemente testes que observam o comportamento público.
4. Execute a suíte afetada usando os comandos do próprio projeto e as ferramentas permitidas.
5. Registre resultados, falhas e verificações que não puderam ser executadas.
